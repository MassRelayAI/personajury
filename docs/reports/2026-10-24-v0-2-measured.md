## What the independent review found

The reviewer built the branch, re-ran the suite (281 passed, the same per-file counts) and reproduced each finding on a real binary.

| id | finding | how it was fixed |
|---|---|---|
| Important 1 | `--stake` and `--draw` under a rule change who sits, with no reason and no record | both are override fields (`stakes`, `draw`) and need a reason |
| Important 2 | one random stream for every term, so adding a persona to one term reshuffled the others | one stream per term, `term_seed(run seed, tag)`; a test adds a persona to term A and checks term B |
| Important 3 | `brief --rule` never checked that the subject falls under that rule, so a human-class page could run a jury | the subject's source paths are classified; a human class refuses (data `{class, path}`) under any override |
| Important 4 | a rule with `spend = 0` on a panel above 12 was refused instead of capped | capped at 12 (1000 with `--allow-large`, a reason above 12), answer carries `capped: true` |
| Important 5 | overflow in the seat sum bypassed the 12/1000 gate and panicked in a debug build | checked sum and estimate; overflow is `panel_too_large`, no orphan run |
| Important 6 | a text attachment refused every locator that was not `L<n>`, and a NUL-bearing binary counted as text | only canonical `L<n>` of a UTF-8, NUL-free file is checked; other anchors behave as in v0.1 |

Minor findings: M1 to M6 fixed (`L+1`, `L01`, `L 1`, `L-1` refused; estimate overflow; the matrix header names the override and its run and
escapes newlines; lens order is not a departure; the ad-hoc query is seeded by its normalised terms; the schema version is probed before any
table is touched, with a readable message). M8 (the ceiling is applied to the selected seats of a saved panel but to the total of an ad-hoc
query) is written into D10. M7 and M9 were left and closed in v0.3 (D12).

## What is left open

- **The ceiling of 12 is a guess.** The saturation run that would decide it (how many jurors before a new one stops adding a new finding) has not been done.
- **`doctor` does not diagnose a refused store:** it fails with the same store error as every other verb.
- **A brief above 12 seats without `--rule` recorded nothing** at v0.2; closed in v0.3 (D12).
- `rustfmt` was not available in the build environment, so the new code is hand-formatted and no file was bulk-formatted.

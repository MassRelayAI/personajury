## What the independent review found

The reviewer re-ran the suite (391 passed), ported the reproductions into 12 probe tests and ran the binary. Verdict: fix first. Every
Critical finding is a case where the one gate an agent obeys with no person watching said `apply`.

| id | finding | how it was fixed |
|---|---|---|
| Critical 1 | a run nobody judged, or whose primary stratum never answered, answered `apply` | `incomplete_jury` (advise): a briefed seat with no accepted verdict |
| Critical 2 | a `--rule` lower than the sources' rule lowered the quorum | the quorum is the highest of the run's, the rule's and the sources'; `rule_below_sources`; a lower rule at `brief` is an override needing `--reason` |
| Critical 3 | the run's rule was not recorded, so dropping `--rule` assumed `low` | `run.rule_class` and `run.quorum` stored (idempotent migration); `quorum_unknown` when none is known |
| Critical 4 | a brief overridden down (an explicit `--spend`, a lens list, or no rule) still applied | `overridden_down` (advise) for spend, lenses, detail, effort, a replaced panel, stakes or draw, or no rule on a ruled subject |
| Critical 5 | with several lens runs a persona's stake came from the last run, hiding a primary blocker | blockers and splits are computed per run with that run's stakes |
| Important 1 | a stale or superseded run still applied | `stale_run` |
| Important 2 | a lens version bump hid the delta | `delta_unavailable` |
| Important 3 | an undecided finding from the previous round did not count | `check_failed` is evaluated over the subject, not the run ids passed |
| Important 4 | the agent could close a human blocker itself with `decide --by agent` | `decide --by-human`; any other `--by` is `human_decision_required` |
| Important 5 | the 7-seat cap dropped whole strata | every cap keeps one seat per stratum |

Minor: M1 (the answer depended on which history was passed; `given` versus `judged`) was not changed. The fix round did not report on M2 (`--effort`
above the toml's needs no reason; the dial table pins it), M3 (the listener guard truncates at the first `//`, though `no_std_network_in_src`
still catches the dodge), M4 (the `.mcpb` tool list is not checked against the seven MCP tools) or M5 (commit trailers); treat them as open.

Checked and sound in the review: the v3 to v4 migration, the MCP agreeing with the CLI byte for byte, human verdicts sitting beside the jury
and never in a median or a split, the budget arithmetic (50000 at 15000 tokens per brief gives 3 briefs; 44999 gives `over_budget`), the
`@model` parser, the byte-identical `lens generate` brief, and every manifest being valid JSON.
